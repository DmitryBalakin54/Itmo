# Генерация данных
1. Выберите любой набор данных для классификации изображений. Желательно, чтобы изображения были небольшого размера, а классов было не так много.

2. Обучите автокодировщик. Постройте кривую обучения. Провизуализируйте, как автокодировщик восстанавливает изображения.

3. Провизуализируйте, как Гауссова модель и SMOTE генерируют изображения в пространстве изображений и в скрытом пространстве автокодировщика. Для пространства изображений (если они большого размера) допускается использовать упрощенную Гауссову модель.

4. Вычислите остаток от деления вашего номера ИСУ на 3 этот номер число 367077. Исходя из этого выберите модель: 0 = вариационный автокодировщик; 1 = генеративно состязательная сеть; 2 = диффузная модель.

5. Обучите выбранную модель условно генерировать изображения напрямую и в пространстве автокодировщика. Провизуализируйте результат. Сгенерируйте изображения из определённых и из смеси классов.
